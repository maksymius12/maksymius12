## <img src="https://cdn-icons-png.flaticon.com/512/1055/1055687.png" width="28"/> About Me

<div align="center">
<table>
<tr>
<td width="100%">

I'm a **student software engineer** based in Kyiv, Ukraine, building production-grade
applications across the full stack — from **Flutter mobile apps backed by Firebase**, to
**React web platforms**, to **AI-integrated tools** powered by the Gemini and Claude APIs.
My work centers on shipping real systems for real users: school management platforms,
loyalty and rewards apps, hackathon infrastructure, and internal tools for educational
institutions serving thousands of students.

I approach engineering with a **product mindset** — prototyping fast in HTML/CSS before
committing to native builds, designing clean data models in Firestore, and obsessing over
UI polish inspired by category-leading fintech apps. I care about **security-conscious API
design**, **role-based access architectures**, and **scalable Firebase backends** that hold
up under real classroom and campus conditions.

Beyond client work, I compete in and lead teams for **international STEM hackathons**
(Infomatrix, NEXGEN UA, Noosphere), combining hardware (ESP32) with mobile software to
build accessible, novel solutions — always validating an idea's uniqueness before writing
a single line of code.
